# 💖 เว็บวันครบรอบ (Anniversary)

เว็บแอปหน้าเดียวฉลองวันครบรอบความรัก ทำด้วย HTML/CSS/JavaScript ล้วน ไม่ต้องติดตั้งอะไร เปิดใช้งานได้ทันที

## ✨ ฟีเจอร์

- ⏱️ **ตัวนับเวลา** — นับว่าอยู่ด้วยกันมากี่ปี/เดือน/วัน + จำนวนวันรวม
- ⏳ **นับถอยหลัง** — เหลืออีกกี่วันถึงวันครบรอบปีถัดไป
- 📅 **ไทม์ไลน์** — เหตุการณ์สำคัญของเราแบบเรียงเวลา
- 🖼️ **แกลเลอรี** — รูปภาพความทรงจำ คลิกดูรูปใหญ่ได้
- 💌 **จดหมายรัก** — ข้อความพิเศษถึงคนรัก
- 🎵 **เพลงประกอบ** — เปิด/ปิดเพลงได้
- 💕 เอฟเฟกต์หัวใจลอย + รองรับมือถือ

## 📂 โครงสร้างไฟล์

```
anniversary/
├── index.html        โครงหน้าเว็บ
├── css/style.css     ดีไซน์
├── js/config.js      ★ แก้ข้อมูลทั้งหมดที่นี่
├── js/app.js         ตรรกะการทำงาน
└── README.md
```

## 🛠️ วิธีปรับแต่งข้อมูลของคุณ

เปิดไฟล์ **`js/config.js`** แล้วแก้ได้เลย:

1. **ชื่อและวันที่เริ่มคบ** → `couple` (ตั้ง `startDate` ให้ตรงกับวันที่เริ่มต้น)
2. **ข้อความหัวเว็บ** → `hero`
3. **จดหมายรัก** → `letter`
4. **รูปภาพ** → `gallery` (ใส่ URL รูป หรือวางไฟล์ไว้ในโฟลเดอร์ `images/` แล้วอ้างอิง เช่น `images/pic1.jpg`)
5. **ไทม์ไลน์** → `timeline`
6. **เพลง** → `music` (วางไฟล์ใน `music/` แล้วตั้ง `src: "music/song.mp3"` หรือใส่ URL; เว้นว่างถ้าไม่ต้องการเพลง)

> รูปตัวอย่างในแกลเลอรีใช้รูปสุ่มจากอินเทอร์เน็ต เปลี่ยนเป็นรูปของคุณได้เลย

## ▶️ เปิดดูในเครื่อง

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย หรือรันเซิร์ฟเวอร์เล็ก ๆ:

```bash
# Python
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

## 🚀 วิธี Deploy ขึ้นเว็บจริง (ฟรี)

### ตัวเลือก A: GitHub Pages
1. push โฟลเดอร์นี้ขึ้น GitHub repo
2. ไปที่ **Settings → Pages**
3. เลือก Branch = `main`, Folder = `/root` (หรือ `/anniversary` ถ้าอยู่ในโฟลเดอร์ย่อย) แล้ว Save
4. รอสักครู่ เว็บจะอยู่ที่ `https://<username>.github.io/<repo>/`

### ตัวเลือก B: Netlify / Vercel (ง่ายสุด)
- ลากโฟลเดอร์ `anniversary` ไปวางที่ [netlify.com/drop](https://app.netlify.com/drop) → ได้ลิงก์ทันที
